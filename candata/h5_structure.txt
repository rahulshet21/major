2. GUI Application: HDFView (macOS)

   - Install via DMG or Homebrew (if available: brew install --cask hdfview).
   - Launch HDFView -> File -> Open -> Select wildfire-s1s2-alos-dataset-canada-uint16.h5.
   - Navigate tree view: 2017 -> CA_2017_BC_1157 -> s1 / s2 / mask.
   - Double-click datasets to view raw 2D/3D slice numerical tables or image visualizer.

3. VS Code / Cursor Extension:
   - Install 'vscode-hdf5' or 'H5 Web' extension from the Extensions Marketplace.
   - Open the file directly in the editor sidebar to visually inspect datasets and metadata.
